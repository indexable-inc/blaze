Inter font files (Inter-*.ttf)
==============================

These static TrueType faces are taken from Inter 4.1 (extras/ttf in the release archive):
  https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

They are licensed under the SIL Open Font License, Version 1.1. The full license text is in
LICENSE.txt in this directory.

den-native sets its text in an installed Inter when the machine has one, and in these otherwise
(text.rs `bundled`), so the brand face (fed1eb428d:docs/research/ra-mir-brand.md) is there on any machine.
