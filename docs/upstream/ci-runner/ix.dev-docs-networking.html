Networking

Your machines reach each other over private links, by name, on any port. Nothing outside the group can reach those addresses. Each link is a tunnel that ends inside the machines at both ends, with a post-quantum key exchange. Every machine and every client gets its own IPv6 address, even behind an IPv4-only router.

To reach a group from your own computer, run ix net up backend. It stays in the foreground and works on Linux only.

Serving the public

Put a port behind ix's HTTPS proxy with ix new --l7-proxy-port 8080, or give a machine its own public IPv4 address with --ipv4. The SDK takes ipv4: true and has no option for the proxy port yet. Outbound traffic is free.

To reach one port of one machine from your own program, call machine.forwardPort(remotePort). It binds a port on the loopback address only.
