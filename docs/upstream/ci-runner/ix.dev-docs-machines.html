Machines

Every ix machine is the same size, and the size is large: 100 vCPUs, 256 GiB of memory and 1 PiB of disk. You never pick an instance type.

Each machine has its own kernel, and the operating system inside is yours to choose. To fit more machines on one host, boot one with fewer vCPUs: ix new --cpus 8 or cpuCores: 8 in the SDK. The count must be 2, 4, 8, 16, 32 or 64. The price does not change with the size. The meters count use.

Stopped is not gone

A machine keeps its disk until you remove it. Stop it and only the disk bills. Start it again and the disk is as you left it.

If a host loses its disk

A machine writes its disk on its host first, and ix copies the writes to ix storage after that. If the host loses its local disk before the copy, the last writes are gone, and ix start refuses to start the machine.

Until you accept the loss, ix writes nothing over what is left of the local writes. Run ix vm accept-loss <machine> to accept the loss. The next ix start then starts the machine from the copy in ix storage and formats over the local writes, so anything that was left of them is gone.

To make sure that the disk is in ix storage, take a snapshot with --wait-durable.

Ephemeral and persistent

A machine is persistent by default. lifetime: "ephemeral" removes it when the scope ends. A ttl makes the platform remove it at the deadline. Leaving the scope of a persistent machine never removes it.

Architecture and CPU

arch is "x86_64" or "arm64". cpu is "epyc-5", "xeon-6" or "graviton-5" and implies its architecture. Leave both unset and the platform picks.

A snapshot or fork keeps the architecture of its machine and never moves to another. A machine pinned with cpu restores only on the same CPU class. A pair that contradicts itself, such as arch: "arm64" with cpu: "epyc-5", fails with invalid_argument.

Live output

machine.exec starts the command and returns a Process at once. Await it for the result, or read stdout and stderr while it runs. Dropping the Process stops the command. The SDK reference lists every member.
